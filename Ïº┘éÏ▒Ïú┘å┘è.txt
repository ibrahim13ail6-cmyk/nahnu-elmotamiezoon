منصة الفرقة الأولى – كلية الزراعة (نسخة مسطّحة بدون مجلدات)

هذه النسخة مناسبة للرفع من الموبايل: كل الملفات في مكان واحد ولا يوجد أي مجلد.

طريقة الرفع:
1) افتح مستودع GitHub ← Add file ← Upload files.
2) اختر كل الملفات (index.html وباقي صفحات html وملفات js وملف style.css وكل صور jpg وملف firestore.rules). ارفعها على دفعتين لو طلب GitHub ذلك (الحد 100 ملف في المرة).
3) اضغط Commit changes. سيتحدث موقع Vercel تلقائيًا.
4) في Firebase: Authentication > Settings > Authorized domains أضف دومين Vercel، ثم Firestore > Rules الصق محتوى firestore.rules واضغط Publish.

مهم: لا ترفع ملف الزيب نفسه، ارفع الملفات بعد فك الضغط. والملفات لازم تكون في أول المستودع.
بعد الرفع افتح: رابط-موقعك/style.css وتأكد أنه يعرض كودًا وليس 404.
